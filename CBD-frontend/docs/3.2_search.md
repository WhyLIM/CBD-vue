# Search Functionality

CBD3 provides search capabilities at multiple entry points throughout the platform.

## Homepage Search

The homepage (`/`) includes a search bar for quick keyword lookup across the biomarker database. Enter a gene symbol, biomarker name, or keyword to jump directly to results.

## Biomarker Page Search

The Biomarker page (`/biomarker`) provides a search bar for filtering biomarker records. Results are displayed in a paginated table with sortable columns.

## Advanced Search

The Advanced Search page (`/search`) supports multi-condition queries:

- Add multiple filter conditions across different fields (e.g., biomarker name, gene symbol, cancer type, stage, experiment method)
- Combine conditions with AND/OR logic
- **Save Conditions**: Save the current set of search conditions for later use
- **Load Conditions**: Reload previously saved search conditions

## Gene Autocomplete

Throughout the platform, gene input fields use autocomplete with the following behavior:

- Type a gene symbol to see matching suggestions from the database
- Autocomplete triggers after a 300ms debounce to reduce server load
- Suggestions are fetched from the backend search API

## Troubleshooting

- **No Results**: Try broader terms or check spelling
- **Too Many Results**: Add more specific filters
- **Slow Performance**: Reduce the search scope by adding filters
