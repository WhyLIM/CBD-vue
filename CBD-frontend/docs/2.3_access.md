# Data Access

CBD3 provides multiple ways to access and explore our comprehensive colorectal cancer biomarker data.

## Web Interface

### Biomarker Browsing

The [Biomarker](/biomarker) page provides structured access to curated biomarker records with pagination and search.

### Explore

- **Gene Expression Atlas** (`/explore`): Interactive UMAP visualization of single-cell gene expression. Select a dataset, cell type, and gene to overlay expression levels on the UMAP plot.
- **Protein Interaction** (`/explore/network`): Browse and explore PPI networks with interactive Cytoscape.js graphs.

### Single-Cell Analyses

The [Analysis](/analysis) page provides seven analysis modules:

| Module | Description |
|--------|-------------|
| DEGs | Differential expressed gene analysis (Original, By Celltype, Tumor vs Normal) |
| KEGG Pathway | KEGG pathway enrichment bubble charts |
| Ridge Ranking | Ridge ranking visualizations |
| Trajectory | Cell trajectory plots and interactive pseudotime analysis |
| CellChat | Cell communication networks (all interactions and biomarker-specific) |
| Network Sensitivity | PRS network sensitivity analysis |
| Predictive Ability | ROC predictive analysis (Tumor vs Normal and By Celltype) |

### Clinical

- **Survival** (`/clinical/survival`): Kaplan-Meier survival curves with gene and clinical parameter filtering
- **Immune** (`/clinical/immune`): Immune infiltration heatmap (full-data, 800px height)

### Other Pages

- **Download** (`/download`): Download data files
- **Submit** (`/submit`): Submit new biomarker data

## API Access

- **RESTful API**: Programmatic access to all CBD3 data
- API documentation is under construction

## Access Levels

- **No Registration Required**: Full browsing, searching, and downloading

## Data Citation

When using CBD3 data, please cite the database and the original data sources where applicable.
