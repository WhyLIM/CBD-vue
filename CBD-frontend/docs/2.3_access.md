# Data Access

CBD3 provides multiple ways to access and explore our comprehensive colorectal cancer biomarker data.

## Web Interface

### Biomarker Browsing

The <a href="/biomarkers">Biomarkers</a> page provides structured access to curated biomarker records with pagination and search (detail pages at `/biomarkers/:id`).

### Explore

- **UMAP Explorer** (`/umap`): Interactive UMAP visualization of single-cell gene expression. Select a dataset, cell type, and gene to overlay expression levels on the UMAP plot.
- **Network Analysis** (`/network`): Build, expand and statistically analyze PPI networks with interactive Cytoscape.js graphs.
- **MAMOF Framework** (`/mamof`): Overview of the Multi-Ancestry Multi-Omics Framework.

### Other Pages

- **Download** (`/download`): Download data files
- **Submission** (`/submission`): Submit new biomarker data

## API Access

- **RESTful API**: The web application communicates with a RESTful backend; public API documentation is under construction

## Access Levels

- **No Registration Required**: Full browsing, searching, and downloading

## Data Citation

When using CBD3 data, please cite the database and the original data sources where applicable.
