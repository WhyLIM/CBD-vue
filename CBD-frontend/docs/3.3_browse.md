# Browse & Analysis

## Biomarker Browser

The [Biomarker](/biomarker) page (`/biomarker`) provides structured access to curated colorectal cancer biomarker records. Records are displayed in a paginated table with columns covering biomarker name, gene symbol, type, category, cancer stage, experiment method, and more. Use the search bar to filter records by keyword.

## Gene Expression Atlas (UMAP)

The [Gene Expression Atlas](/explore) (`/explore`) visualizes single-cell RNA-seq data as interactive UMAP plots.

- **Dataset Selection**: Choose from available scRNA-seq datasets
- **Cell Type Filter**: Filter cells by annotated cell type
- **Gene Expression Overlay**: Enter a gene symbol (with autocomplete) to color-code cells by expression level
- **Default Loading**: The UMAP plot loads 10,000 cells by default for performance

## Protein Interaction Network

The [Protein Interaction](/explore/network) page (`/explore/network`) displays protein-protein interaction (PPI) networks using Cytoscape.js.

- Interactive network graph with zoom and pan
- Nodes represent proteins, edges represent interactions
- Data sourced from the STRING database

## Single-Cell Analyses

The [Analysis](/analysis) page (`/analysis`) provides seven analysis modules as tabbed sections:

### DEGs (Differential Expressed Genes)

Three sub-tabs:

1. **Original**: Volcano plot displaying the full dataset as a scatter plot (no pagination), with a paginated data table below. Use the gene search box (with autocomplete) to highlight specific genes.
2. **By Celltype**: Differential gene analysis grouped by cell type.
3. **Tumor vs Normal**: Tumor vs Normal comparison of differentially expressed genes.

All gene search boxes support autocomplete.

### KEGG Pathway

KEGG pathway enrichment analysis displayed as interactive bubble charts. Bubble size indicates gene count, color indicates significance.

### Ridge Ranking

Ridge ranking chart visualization for gene expression distribution across cell types.

### Trajectory

Two sub-sections:

1. **Cell Trajectory**: Cell trajectory plots. Filter by Cell Type and Plot Type.
2. **Interactive Pseudotime**: Interactive pseudotime analysis with three modes:
   - By State
   - By Pseudotime
   - Gene Expression (with gene autocomplete)

### CellChat (Cell Communication)

Two views:

1. **All Interactions**: Full cell-cell communication network graph
2. **Biomarker as Ligand / Receptor**: Enter a gene symbol to view its specific ligand or receptor interaction networks

### Network Sensitivity

PRS (Polygenic Risk Score) network sensitivity analysis. Enter a gene symbol (with autocomplete) to visualize the network sensitivity results.

### Predictive Ability

ROC curve analysis for predictive ability assessment. Two sub-tabs:

1. **Tumor vs Normal**: ROC analysis comparing tumor and normal samples
2. **By Celltype**: ROC analysis grouped by cell type

Features gene autocomplete and AUC value filtering.

## Clinical Analysis

### Survival Analysis

The [Survival](/clinical/survival) page (`/clinical/survival`) provides Kaplan-Meier survival curves.

- Filter by gene symbol (with autocomplete)
- Filter by clinical parameters (e.g., cancer stage, gender, age group)
- Compare survival curves between high and low expression groups

### Immune Infiltration

The [Immune](/clinical/immune) page (`/clinical/immune`) displays an immune infiltration heatmap.

- Renders full data (no pagination)
- Fixed 800px height
- X-axis labels rotated 45 degrees for readability

## Data Export

Charts throughout the platform can be exported as images (PNG/SVG) using the built-in ECharts or Cytoscape.js export functionality.
