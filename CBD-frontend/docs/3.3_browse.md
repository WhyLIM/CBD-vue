# Browse & Analysis

## Biomarker Browser

The <a href="/biomarkers">Biomarkers</a> page (`/biomarkers`) provides structured access to curated colorectal cancer biomarker records. Records are displayed in a paginated table with columns covering biomarker name, gene symbol, type, category, cancer stage, experiment method, and more. Use the search bar to filter records by keyword.

## Gene Expression Atlas (UMAP)

The <a href="/umap">UMAP Explorer</a> (`/umap`) visualizes single-cell RNA-seq data as interactive UMAP plots.

- **Dataset Selection**: Choose from available scRNA-seq datasets
- **Cell Type Filter**: Filter cells by annotated cell type
- **Gene Expression Overlay**: Enter a gene symbol (with autocomplete) to color-code cells by expression level
- **Default Loading**: The UMAP plot loads 10,000 cells by default for performance

## Network Analysis

The <a href="/network">Network Analysis</a> page (`/network`) displays protein-protein interaction (PPI) networks using Cytoscape.js, with data from the STRING database (v12.0).

- Build networks from manual input, CBD database proteins or file upload (12,000+ species)
- Expand networks with high-confidence first-shell partners (instant local index for human)
- Evidence-based edge coloring, module detection (Louvain), enrichment, proximity testing and set comparison
- Export PNG/SVG images, GraphML for Cytoscape desktop, and a full JSON analysis snapshot

See [Network Analysis](3.5_network.md) for the complete feature guide.

## MAMOF Framework

The <a href="/mamof">MAMOF Framework</a> page (`/mamof`) introduces the Multi-Ancestry Multi-Omics Framework - the computational approach behind CBD3 for identifying universal and population-specific colorectal cancer biomarkers, including an illustrated overview of the analysis pipeline.

The single-cell analysis suite and the clinical analysis pages (survival, immune infiltration) are planned for a future release - see the [Update & TODO List](6_update.md).

## Data Export

Charts throughout the platform can be exported as images (PNG/SVG) using the built-in ECharts or Cytoscape.js export functionality.
