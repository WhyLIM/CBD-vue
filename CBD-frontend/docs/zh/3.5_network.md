# 网络分析

<a href="/network">网络分析</a>页面（`/network`）提供蛋白质互作（PPI）网络的交互式探索与统计分析，数据来自 [STRING](https://string-db.org) 数据库（v12.0），使用 Cytoscape.js 渲染。

## 使用流程

1. **建网** —— 输入蛋白（或从数据库加载），设置参数后点击 *Generate Network*
2. **扩展** —— 用高置信度互作伙伴扩展网络
3. **分析** —— 拓扑、富集、模块、邻近性检验与集合对比
4. **下载** —— 导出可直接用于发表的图片和完整、可复现的分析包

## 构建网络

### 输入方式

| 方式 | 说明 |
|------|------|
| **Manual Input** | 每行一个，输入蛋白名称/基因符号 |
| **From Database** | 从 CBD 数据库已整理的蛋白中选择 |
| **File Upload** | 上传 `.txt`/`.csv` 文件（每行一个蛋白） |

建网前会进行 **ID 映射报告**：将输入解析到 STRING，并报告无法匹配的名称。

### 参数

- **Species（物种）** —— 支持 STRING 全部 12,000+ 物种（可搜索列表）。本地索引功能（即时扩展、邻近性检验）仅限人类。
- **Confidence Score（置信度）** —— 互作纳入的最低 combined score（0–1000）；400 对应中等置信度（STRING 默认）。
- **Network Type（网络类型）** —— *Functional* 汇总全部证据通道；*Physical* 仅保留直接物理结合。
- **Edge Coloring（边配色）** —— *Confidence*（按 combined score 灰色渐变）或 *Evidence*（按主导证据通道着色，图上带图例）。
- **Hide disconnected nodes** —— 隐藏因过滤而失去所有连边的蛋白。

## 网络扩展

*First-shell Partners* 为当前网络中的每个蛋白添加得分最高的 STRING 互作伙伴（每个蛋白 0–20 个）。

- **人类**网络使用内置的本地 STRING 索引（combined score ≥ 400）——即时完成，即使服务器无法访问 string-db.org 也可用。
- 其他物种通过 STRING API 实时扩展。
- 扩展会重新计算统计与拓扑；模块、邻近性与路径结果会因网络变化而重置。可反复应用持续扩大网络。

## 可视化

- **布局** —— 力导向（cose-bilkent）、cose、环形、网格、层级、同心共 6 种布局循环切换；支持缩放与平移。
- **证据通道图例** —— 边配色设为 *Evidence* 时自动显示。
- **节点/边对话框** —— 点击节点查看度、中心性、所属模块及懒加载的**功能注释**；点击边查看置信度、主导证据通道及懒加载的**支撑文献**（Europe PMC 共被引检索，链接 PubMed）。
- **View in CBD** —— 从网络节点直接跳转到 CBD 数据库中对应的生物标志物条目。
- **最短路径搜索** —— 高亮网络中任意两个蛋白之间的连接路径。

### 配色方案

默认 **Morandi · Light**（莫兰迪浅色，低饱和灰调），可切换 **Morandi · Classic** 或 **Classic**，也可完全自定义：自行挑选节点颜色与 15 个模块颜色。选择保存在浏览器中并实时生效。模块数超过色板时自动生成互不重复的新颜色。

## 分析标签页

### Topology（拓扑）

按蛋白排序的指标表格：

| 指标 | 含义 |
|------|------|
| Degree | 蛋白在网络内的连接数 |
| Betweenness | 经过该节点的最短路径数量（桥接/枢纽重要性） |
| Closeness | 到其余所有节点平均距离的倒数 |
| Clustering | 邻居之间互连的程度（1 = 邻居完全互连） |

该标签页还提供**实时边过滤**（低于置信度阈值的边直接隐藏，无需重新请求）和**最短路径搜索**。

### Enrichment（富集）

由 STRING 计算的过表达分析，按类别分组（GO Process/Function/Component、KEGG、Reactome、WikiPathways、HPO、DISEASES、PMID 等）。列：Term（带链接）、Description、Genes（输入蛋白中命中数）、P-value 与 FDR——判断显著性请以 FDR 为准。

### Modules（模块）

使用 **Louvain 算法**的社区发现。节点按模块着色；表格报告模块大小、内部连边数与密度，支持在图中**隔离**单个模块或运行**模块级富集**。

### Proximity Test（邻近性检验）

检验蛋白集是否比随机情况更显著地互连，基于本地人类 STRING 网络（combined score ≥ 400）并进行度匹配随机化：

- **Cohesion（凝聚度）** —— 蛋白集内部连边数 vs. 随机集合（主统计量）；报告 z 分数、经验 p 值及置换分布直方图
- **Proximity（邻近性）** —— 蛋白集内部平均最短距离 vs. 随机集合（Menche 风格）
- 解读：z > 2 且 p < 0.05 表示蛋白集在功能上显著聚集，而非随机组合

### Compare（集合对比）

输入两个蛋白集（A 与 B）构建并集网络，节点按归属着色——陶土色（仅 A）、蓝灰色（仅 B）、灰紫色（共有）——并给出重叠统计与 **Jaccard 指数** |A∩B| / |A∪B|。

## 下载结果

| 按钮 | 内容 |
|------|------|
| **PNG / SVG** | 当前样式（颜色与布局）的网络图片 |
| **GraphML** | 可导入 Cytoscape 桌面版的网络文件，含拓扑属性 |
| **Download All** | 完整分析包：当前边列表（TSV，含证据通道分数）、富集表（TSV）、模块归属（TSV）、GraphML 文件，以及涵盖所有分析与参数的完整 JSON 快照 |

分析包直接从当前内存状态生成——不做任何二次请求——因此下载内容始终与屏幕所见一致。

## 实现说明

- 网络与富集数据经 CBD 后端代理（浏览器不直连 string-db.org）
- 本地人类 STRING 索引（combined score ≥ 400，约 1.95 万蛋白 / 46.5 万边）同时支撑 PRS 网络功能
- 文献检索由 [Europe PMC](https://europepmc.org) 提供
