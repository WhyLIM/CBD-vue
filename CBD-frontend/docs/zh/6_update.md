# 更新与待办事项

## 版本历史

### 版本 3.0.0（最新）

- **发布日期**：2025/12/12
- **主要功能**：
  - 使用 Vue 3 + Vite 完全重新设计平台
  - 生物标志物浏览与搜索
  - UMAP 单细胞基因表达可视化（Gene Expression Atlas）
  - PPI 蛋白质互作网络（Protein Interaction）
  - 综合单细胞分析模块：
    - DEGs 差异表达基因（Original / By Celltype / Tumor vs Normal）
    - KEGG 通路富集分析
    - Ridge 排名图
    - 轨迹分析与交互式伪时间分析
    - CellChat 细胞通讯分析
    - 网络敏感性分析
    - ROC 预测能力分析
  - 临床分析：Kaplan-Meier 生存曲线、免疫浸润热力图
  - 高级搜索与基因自动补全
  - 数据下载与提交
  - 双语文档（英文/中文）

### 版本 1.0.0

- **发布日期**：2018
- **功能**：
  - 基本生物标志物数据库
  - 简单搜索功能
