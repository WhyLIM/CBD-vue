# 更新与待办事项

## 版本历史

### 版本 3.1.0（最新）

- **发布日期**：2026/09/20
- **网络分析模块重大升级**（`/network`）：
  - 建网前提供 ID 映射报告，未匹配名称明确提示
  - 支持 STRING 全部 12,000+ 物种；修复文件上传输入
  - **网络扩展**：添加高置信一阶互作伙伴（每蛋白 0-20 个）；人类网络使用内置本地 STRING 索引（即时、离线可用）
  - 可视化：莫兰迪配色体系（预设 + 完全自定义调色板）；证据通道边配色与图例；节点大小/颜色映射中心性指标；实时置信度边过滤；最短路径高亮；6 种布局（新增 cose-bilkent）；网络淡入动画
  - 节点对话框：STRING 功能注释与 CBD 条目深链；边对话框：主导证据通道与支撑文献（Europe PMC）
  - 分析标签页：拓扑（含路径搜索）、富集（含 FDR 与基因数）、**模块**（Louvain 检测、隔离、模块级富集）、**邻近性检验**（本地人类索引上的凝聚度 z 分数 / 经验 p 值）、**集合对比**（并集网络着色与 Jaccard 指数）
  - 下载：PNG/SVG/GraphML 以及完整分析包（边 TSV、富集 TSV、模块归属、GraphML、JSON 快照），全部从屏幕当前状态生成
  - 后端：新增 STRING 代理路由（resolve / expand / abstracts / annotations / species / proximity）与独立限流；全局 API 限流对 STRING 路由放宽

### 版本 3.0.0

- **发布日期**：2025/12/12
- **主要功能**：
  - 使用 Vue 3 + Vite 完全重新设计平台
  - 生物标志物浏览与搜索
  - UMAP 单细胞基因表达可视化（Gene Expression Atlas）
  - PPI 蛋白质互作网络（Protein Interaction）
  - 高级搜索与基因自动补全
  - 数据下载与提交
  - 双语文档（英文/中文）

### 版本 1.0.0

- **发布日期**：2018
- **功能**：
  - 基本生物标志物数据库
  - 简单搜索功能
