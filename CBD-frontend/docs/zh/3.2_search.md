# 搜索功能

CBD3 提供多个入口进行生物标志物和相关数据的搜索。

## 首页搜索

首页提供快速搜索框，用户可输入基因名称或关键词，直接跳转到对应的生物标志物或分析结果。

## Biomarker 页面搜索

Biomarker 页面（`/biomarker`）提供：
- 关键词搜索框，支持按基因名称、描述等字段筛选
- 分页表格浏览全部生物标志物记录

## 高级搜索

Advanced Search 页面（`/search`）提供多条件组合搜索：
- 支持按多个字段设置筛选条件
- 可保存常用搜索条件，方便下次使用

## 基因自动补全

以下模块中的基因搜索框均支持自动补全功能：
- DEGs 分析（Original / By Celltype / Tumor vs Normal）
- Trajectory 的 Interactive Pseudotime（Gene Expression 模式）
- CellChat（Biomarker as Ligand / Receptor）
- Network Sensitivity
- Predictive Ability

输入时自动触发后端搜索 API（300ms 防抖），从数据库中匹配基因名称并显示候选列表。

## 故障排除

### 常见问题

- **无结果**：尝试更广泛的术语或检查拼写
- **结果过多**：添加更具体的过滤条件
- **性能缓慢**：减少搜索范围或添加过滤条件
