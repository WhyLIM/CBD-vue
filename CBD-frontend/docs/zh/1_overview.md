# 介绍与概述

## 介绍

CBD3（结直肠癌生物标志物数据库 v3）是一个集成生物标志物、临床数据和单细胞RNA测序数据的综合分析平台，旨在加速结直肠癌研究。

## 核心功能

- **生物标志物浏览**：从精选医学文献中整理并手动验证的结直肠癌生物标志物数据库
- **单细胞基因表达图谱**：基于 UMAP 的交互式单细胞基因表达可视化
- **蛋白质互作网络**：基于 Cytoscape.js 的 PPI 网络浏览与探索
- **综合单细胞分析**：
  - DEGs（差异表达基因）：火山图与分页表格
  - KEGG 通路富集分析
  - Ridge 排名图
  - 轨迹分析与伪时间分析
  - CellChat 细胞通讯分析
  - 网络敏感性分析
  - ROC 预测能力分析
- **临床分析**：Kaplan-Meier 生存曲线、免疫浸润热力图
- **数据下载与提交**：支持数据导出和社区贡献

## 数据来源

- **PubMed 文献**：手工整理的生物标志物数据
- **TCGA**：COAD/READ 临床验证数据与生存数据
- **GEO**：单细胞 RNA 测序数据
- **STRING**：蛋白质-蛋白质相互作用网络
- **DrugBank**：药物与靶点数据

## 技术栈

- **前端**：Vue 3 + Vite + Element Plus + ECharts + Cytoscape.js
- **后端**：Node.js + Express 5 + MySQL2
- **数据库**：MySQL（12 张核心表，约 3640 万行数据）
- **包管理**：pnpm
