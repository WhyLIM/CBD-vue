# 浏览与分析

## 生物标志物浏览器

Biomarkers 页面（`/biomarkers`）提供整理的结直肠癌生物标志物数据库的结构化访问，以分页表格形式展示所有记录（详情页 `/biomarkers/:id`）。

## Gene Expression Atlas（UMAP 单细胞基因表达可视化）

路径：`/umap`

- **筛选器**：Dataset 选择、Cell Type 选择
- **功能**：基于 UMAP 降维的细胞分布图，默认加载 10000 个细胞
- **基因表达叠加**：选择基因后，UMAP 图上以颜色梯度展示该基因的表达水平
- **交互**：支持缩放、平移

## Network Analysis（网络分析）

路径：`/network`

- **功能**：基于 Cytoscape.js 的 PPI 蛋白质互作网络构建、扩展与统计（STRING v12.0，支持 12,000+ 物种）
- **分析**：富集分析、Louvain 模块检测、邻近性检验、集合对比、最短路径
- **导出**：PNG/SVG 图片、Cytoscape 桌面版 GraphML、完整 JSON 分析快照

完整功能说明见[网络分析](3.5_network.md)。

## MAMOF Framework（多族群多组学框架）

路径：`/mamof`

- MAMOF（Multi-Ancestry Multi-Omics Framework）框架介绍页，说明 CBD3 用于发现通用型与族群特异性结直肠癌生物标志物的计算方法
- 提供分析流程图解与全屏查看

单细胞分析套件与临床分析页面（生存分析、免疫浸润）计划在后续版本上线 - 见[更新与待办事项](6_update.md)。

## 数据导出选项

### 导出格式

- **CSV/Excel**：用于电子表格分析
- **PNG/SVG**：用于出版级图形
