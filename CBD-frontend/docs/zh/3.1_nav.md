# 导航概述

## 平台布局

CBD3 网站通过顶部导航栏组织为以下主要部分：

### 主导航

| 菜单项 | 路由 | 说明 |
|--------|------|------|
| **Home** | `/` | 首页，平台概览与快速搜索 |
| **Biomarkers** | `/biomarkers` | 生物标志物浏览与搜索（详情页 `/biomarkers/:id`） |
| **Advanced Search** | `/advanced` | 高级搜索，支持多条件筛选 |

### Explore（下拉）

| 子项 | 路由 | 说明 |
|------|------|------|
| Network Analysis | `/network` | 蛋白质互作网络的交互式探索与统计（STRING） |
| UMAP Explorer | `/umap` | UMAP 单细胞基因表达可视化 |
| MAMOF Framework | `/mamof` | 多族群多组学框架（MAMOF）介绍 |

### 其他页面

| 菜单项 | 路由 | 说明 |
|--------|------|------|
| **Download** | `/download` | 数据下载 |
| **Submission** | `/submission` | 数据提交 |
| **About** | `/about` | 平台与团队介绍 |

### 页脚链接

- **快速链接**：CBD3 团队成员所属的工作单位
- **帮助信息**：帮助中心（本站点）
- **技术支持**：主要技术支持
