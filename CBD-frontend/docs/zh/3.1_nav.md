# 导航概述

## 平台布局

CBD3 网站通过顶部导航栏组织为以下主要部分：

### 主导航

| 菜单项 | 路由 | 说明 |
|--------|------|------|
| **Home** | `/` | 首页，平台概览与快速搜索 |
| **Biomarker** | `/biomarker` | 生物标志物浏览与搜索 |
| **Advanced Search** | `/search` | 高级搜索，支持多条件筛选 |
| **Explore** (下拉) | | 数据探索 |
| -- Gene Expression Atlas | `/explore` | UMAP 单细胞基因表达可视化 |
| -- Protein Interaction | `/explore/network` | PPI 蛋白质互作网络 |
| **Single-Cell Analyses** | `/analysis` | 综合单细胞分析（7 个模块） |
| **Clinical** (下拉) | | 临床分析 |
| -- Survival | `/clinical/survival` | Kaplan-Meier 生存分析 |
| -- Immune | `/clinical/immune` | 免疫浸润热力图 |
| **Download** | `/download` | 数据下载 |
| **Submit** | `/submit` | 数据提交 |
| **Help** | `/help` | 帮助文档中心 |

### Single-Cell Analyses 内部模块

Single-Cell Analyses 页面包含以下 7 个分析选项卡：

1. **DEGs** - 差异表达基因（Original / By Celltype / Tumor vs Normal）
2. **KEGG Pathway** - KEGG 通路富集分析
3. **Ridge Ranking** - Ridge 排名图
4. **Trajectory** - 轨迹分析（Cell Trajectory + Interactive Pseudotime）
5. **CellChat** - 细胞通讯分析（All Interactions / Biomarker as Ligand / Receptor）
6. **Network Sensitivity** - 网络敏感性分析
7. **Predictive Ability** - ROC 预测能力（Tumor vs Normal / By Celltype）
