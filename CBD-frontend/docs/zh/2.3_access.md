# 数据访问

CBD3 提供多种方式来访问和下载结直肠癌生物标志物数据。

## 访问方式

### Web 界面

CBD3 的 Web 界面提供以下功能模块：

- **Biomarker 浏览**：浏览和搜索整理的结直肠癌生物标志物数据库，支持分页表格浏览
- **Explore（探索）**：
  - Gene Expression Atlas：基于 UMAP 的单细胞基因表达可视化，支持选择 Dataset、Cell Type 和基因表达叠加
  - Protein Interaction：基于 Cytoscape.js 的 PPI 蛋白质互作网络浏览
- **Single-Cell Analyses（单细胞分析）**：7 个分析模块
  - DEGs：差异表达基因分析（火山图 + 表格）
  - KEGG Pathway：KEGG 通路富集气泡图
  - Ridge Ranking：Ridge 排名图
  - Trajectory：轨迹分析与伪时间分析
  - CellChat：细胞通讯网络分析
  - Network Sensitivity：网络敏感性分析
  - Predictive Ability：ROC 预测能力分析
- **Clinical（临床分析）**：
  - Survival：Kaplan-Meier 生存曲线分析
  - Immune：免疫浸润热力图
- **Download**：数据下载页面
- **Submit**：数据提交页面

1. **CBD3 数据库**：引用数据库本身
2. **原始来源**：适用时引用主要数据来源
