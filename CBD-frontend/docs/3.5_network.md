# Network Analysis

The <a href="/network">Network Analysis</a> page (`/network`) provides interactive exploration and statistical analysis of protein-protein interaction (PPI) networks, powered by the [STRING](https://string-db.org) database (v12.0) and rendered with Cytoscape.js.

## Workflow Overview

1. **Build** — enter proteins (or load them), set parameters, and click *Generate Network*
2. **Expand** — grow the network with high-confidence interaction partners
3. **Analyze** — topology, enrichment, modules, proximity testing and set comparison
4. **Download** — export publication-ready images and a complete, reproducible analysis bundle

## Building a Network

### Input Methods

| Method | Description |
|--------|-------------|
| **Manual Input** | Type protein names/gene symbols, one per line |
| **From Database** | Select proteins curated in the CBD database |
| **File Upload** | Upload a `.txt`/`.csv` file with one protein per line |

Before the network is built, an **ID mapping report** resolves your input against STRING and reports any names that could not be matched.

### Parameters

- **Species** — all 12,000+ STRING species are supported (searchable list). Local-index features (instant expansion, proximity test) are human-only.
- **Confidence Score** — minimum combined score (0–1000) for an interaction to be included; 400 corresponds to medium confidence (STRING default).
- **Network Type** — *Functional* aggregates all evidence channels; *Physical* keeps only direct physical binding.
- **Edge Coloring** — *Confidence* (gray gradient by combined score) or *Evidence* (color by dominant evidence channel, with an on-graph legend).
- **Hide disconnected nodes** — removes proteins left without visible edges.

## Network Expansion

*First-shell Partners* adds the top-scoring STRING interaction partners of each protein in the current network (0–20 per protein).

- **Human** networks use a bundled local STRING index (combined score ≥ 400) — expansion is instant and works even when string-db.org is unreachable from the server.
- Other species are expanded through the live STRING API.
- Expanding recomputes statistics and topology; module, proximity and path results are reset because the network changed. Apply repeatedly to grow the network further.

## Visualization

- **Layouts** — cycle through force-directed (cose-bilkent), cose, circular, grid, breadth-first and concentric arrangements; zoom and pan supported.
- **Evidence channel legend** — displayed when edge coloring is set to *Evidence*.
- **Node / edge dialogs** — click a node for its degree, centrality values, module membership and lazily loaded **functional annotations**; click an edge for its confidence score, dominant evidence channel and lazily loaded **supporting publications** (Europe PMC co-citation search, linked to PubMed).
- **View in CBD** — jump from a network node to the matching biomarker entry in the CBD database.
- **Shortest path finder** — highlight the route connecting any two proteins of the network.

### Color Schemes

The default **Morandi · Light** palette (muted, low-saturation tones) can be switched to **Morandi · Classic** or **Classic**, or fully customized: pick the node color and the 15 module colors yourself. The choice is stored in the browser and applied live. Modules beyond the palette receive automatically generated distinct colors.

## Analysis Tabs

### Topology

Sortable table of per-protein metrics:

| Metric | Meaning |
|--------|---------|
| Degree | Number of connections within the network |
| Betweenness | Number of shortest paths passing through the node (bridge/hub importance) |
| Closeness | Inverse average distance to all other nodes |
| Clustering | How interconnected a protein's neighbours are (1 = complete neighbourhood) |

The tab also provides the **live edge filter** (hide edges below a confidence threshold without refetching) and the **shortest path finder**.

### Enrichment

Over-representation analysis computed by STRING, grouped by category (GO Process/Function/Component, KEGG, Reactome, WikiPathways, HPO, DISEASES, PMID and more). Columns: Term (linked), Description, Genes (input proteins in the term), P-value and FDR — judge significance by FDR.

### Modules

Community detection with the **Louvain algorithm**. Nodes are colored by module; the table reports module size, internal edges and density, with actions to **isolate** a module in the graph or run **module-level enrichment**.

### Proximity Test

Statistical test of whether your protein set is more interconnected than expected by chance, run on the local human STRING network (combined score ≥ 400) with degree-matched randomization:

- **Cohesion** — internal edge count of your set vs. random sets (primary statistic); report z-score and empirical p-value with a permutation histogram
- **Proximity** — mean shortest distance within your set vs. random sets (Menche-style)
- Interpretation: z > 2 and p < 0.05 indicate a functionally cohesive, non-random protein set

### Compare

Enter two protein sets (A and B) to build their union network, colored by membership — clay (A only), dusty blue (B only), mauve (shared) — with overlap statistics and the **Jaccard index** |A∩B| / |A∪B|.

## Downloading Results

| Button | Content |
|--------|---------|
| **PNG / SVG** | The styled network exactly as shown (current colors and layout) |
| **GraphML** | The network for import into Cytoscape desktop, including topology attributes |
| **Download All** | Complete analysis bundle: displayed edges (TSV, with evidence channel scores), enrichment table (TSV), module assignments (TSV), the GraphML file, and a full JSON snapshot of every analysis and parameter |

The bundle is generated from the current in-memory state — no re-fetching — so downloaded files always match what is on screen.

## Implementation Notes

- Network and enrichment data are proxied through the CBD backend (never fetched directly from the browser)
- The local human STRING index (`combined score ≥ 400`, ~19.5k proteins / ~465k edges) also powers the PRS network features
- Literature search is provided by [Europe PMC](https://europepmc.org)
