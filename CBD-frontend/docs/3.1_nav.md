# Navigation Overview

## Platform Layout

CBD3 is organized into the following main sections accessible through the top navigation bar:

### Main Navigation

| Menu Item | Route | Description |
|-----------|-------|-------------|
| **Home** | `/` | Platform homepage with overview and quick search |
| **Biomarkers** | `/biomarkers` | Browse and search curated biomarker records (detail pages at `/biomarkers/:id`) |
| **Advanced Search** | `/advanced` | Multi-condition search with save/load support |

### Explore (Dropdown)

| Sub-Item | Route | Description |
|----------|-------|-------------|
| Network Analysis | `/network` | Interactive PPI network exploration and statistics (STRING) |
| UMAP Explorer | `/umap` | UMAP single-cell gene expression visualization |
| MAMOF Framework | `/mamof` | Multi-Ancestry Multi-Omics Framework overview |

### Other Pages

| Menu Item | Route | Description |
|-----------|-------|-------------|
| **Download** | `/download` | Data download page |
| **Submission** | `/submission` | Data submission page |
| **About** | `/about` | About the platform and team |

### Footer

- **Quick Links**: Affiliated research institutions
- **Help Center**: Help documentation (this site)
- **Technical Support**: Contact and support information
