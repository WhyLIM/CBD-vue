# Navigation Overview

## Platform Layout

CBD3 is organized into the following main sections accessible through the top navigation bar:

### Main Navigation

| Menu Item | Route | Description |
|-----------|-------|-------------|
| **Home** | `/` | Platform homepage with overview and quick search |
| **Biomarker** | `/biomarker` | Browse and search curated biomarker records |
| **Advanced Search** | `/search` | Multi-condition search with save/load support |

### Explore (Dropdown)

| Sub-Item | Route | Description |
|----------|-------|-------------|
| Gene Expression Atlas | `/explore` | UMAP single-cell gene expression visualization |
| Protein Interaction | `/explore/network` | PPI protein-protein interaction network |

### Single-Cell Analyses

| Route | Description |
|-------|-------------|
| `/analysis` | Comprehensive single-cell analysis with 7 modules: DEGs, KEGG Pathway, Ridge Ranking, Trajectory, CellChat, Network Sensitivity, Predictive Ability |

### Clinical (Dropdown)

| Sub-Item | Route | Description |
|----------|-------|-------------|
| Survival | `/clinical/survival` | Kaplan-Meier survival analysis |
| Immune | `/clinical/immune` | Immune infiltration heatmap |

### Other Pages

| Menu Item | Route | Description |
|-----------|-------|-------------|
| **Download** | `/download` | Data download page |
| **Submit** | `/submit` | Data submission page |
| **Help** | `/help` | Help documentation center |

### Footer

- **Quick Links**: Affiliated research institutions
- **Help Center**: Link to the help documentation
- **Technical Support**: Contact and support information
