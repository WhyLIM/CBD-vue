On this page

浏览与分析 ​

生物标志物浏览器 ​

Biomarker 页面（/biomarker）提供整理的结直肠癌生物标志物数据库的结构化访问，以分页表格形式展示所有记录。

Gene Expression Atlas（UMAP 单细胞基因表达可视化） ​

路径：/explore

  • 筛选器：Dataset 选择、Cell Type 选择
  • 功能：基于 UMAP 降维的细胞分布图，默认加载 10000 个细胞
  • 基因表达叠加：选择基因后，UMAP 图上以颜色梯度展示该基因的表达水平
  • 交互：支持缩放、平移

Protein Interaction Network（蛋白质互作网络） ​

路径：/explore/network

  • 功能：基于 Cytoscape.js 的 PPI 蛋白质互作网络浏览
  • 交互：支持缩放、平移、节点拖拽

Single-Cell Analyses（单细胞分析） ​

路径：/analysis，包含以下 7 个分析模块：

DEGs（差异表达基因） ​

三个选项卡：

  • Original：按 Cell Type 的火山图（全量散点数据渲染，不分页）+ 分页数据表格
  • By Celltype：差异基因分析，按细胞类型分组
  • Tumor vs Normal：肿瘤与正常组织对比的差异基因分析

所有选项卡均提供基因搜索框（自动补全）。

KEGG Pathway（KEGG 通路富集分析） ​

  • KEGG 通路富集气泡图
  • 展示差异基因在各通路中的富集情况

Ridge Ranking（Ridge 排名图） ​

  • Ridge 排名可视化，展示基因在不同条件下的排名分布

Trajectory（轨迹分析） ​

两个子模块：

  • Cell Trajectory（细胞轨迹图）：按 Cell Type / Plot Type 筛选的细胞轨迹可视化
  • Interactive Pseudotime（交互式伪时间分析）：
    • By State 模式：按细胞状态着色
    • By Pseudotime 模式：按伪时间着色
    • Gene Expression 模式：选择基因后按表达水平着色（支持基因自动补全）

CellChat（细胞通讯分析） ​

三个子模块：

  • All Interactions：全量细胞通讯网络图
  • Biomarker as Ligand：特定基因作为配体的网络（基因自动补全）
  • Biomarker as Receptor：特定基因作为受体的网络（基因自动补全）

Network Sensitivity（网络敏感性分析） ​

  • 基因搜索框（自动补全）
  • 展示选定基因的网络敏感性 PRS 分析结果

Predictive Ability（预测能力 ROC 分析） ​

两个选项卡：

  • Tumor vs Normal：肿瘤 vs 正常组织的 ROC 曲线
  • By Celltype：按细胞类型的 ROC 曲线

功能特性：

  • 基因搜索框（自动补全）
  • AUC 筛选过滤
  • ROC 曲线与 AUC 数值展示

Clinical（临床分析） ​

Survival（生存分析） ​

路径：/clinical/survival

  • Kaplan-Meier 生存曲线
  • 支持筛选基因和临床参数
  • 按分组展示生存差异

Immune（免疫浸润） ​

路径：/clinical/immune

  • 免疫浸润热力图（全量数据渲染）
  • 图表高度 800px，横坐标标签旋转 45 度

数据导出选项 ​

导出格式 ​

  • CSV/Excel：用于电子表格分析
  • PNG/SVG：用于出版级图形
