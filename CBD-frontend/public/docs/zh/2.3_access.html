数据访问 ​

CBD3 提供多种方式来访问和下载结直肠癌生物标志物数据。

访问方式 ​

Web 界面 ​

CBD3 的 Web 界面提供以下功能模块：

  • Biomarkers 浏览：浏览和搜索整理的结直肠癌生物标志物数据库，支持分页表格浏览（详情页 /biomarkers/:id）
  • Network Analysis（网络分析，/network）：PPI 网络的构建、扩展与统计分析（STRING）
  • UMAP Explorer（/umap）：基于 UMAP 的单细胞基因表达可视化，支持选择 Dataset、Cell Type 和基因表达叠加
  • MAMOF Framework（/mamof）：多族群多组学框架介绍
  • Download（/download）：数据下载页面
  • Submission（/submission）：数据提交页面

API 访问 ​

  • RESTful API：对 CBD3 数据的程序化访问

访问级别 ​

  • 无需注册：所有功能均可免费使用，无需注册

数据使用协议 ​

  • 研究目的：学术和非营利研究
  • 教育用途：教学和学习活动
  • 个人分析：个人研究和学习

数据引用 ​

引用要求 ​

使用 CBD3 数据时，请引用：

  1. CBD3 数据库：引用数据库本身
  2. 原始来源：适用时引用主要数据来源
