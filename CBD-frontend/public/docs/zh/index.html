结直肠癌生物标志物的综合平台。

开始使用
在 GitHub 上查看
📊

综合生物标志物分析

包含从精选医学文献中整理并手动验证的结直肠癌生物标志物，提供详细的临床相关性和生存分析。

🔬

单细胞表达图谱

交互式 UMAP 单细胞基因表达可视化——选择数据集、筛选细胞类型并叠加基因表达水平。

🧬

蛋白质相互作用网络

基于 STRING 集成构建、扩展并统计分析蛋白质-蛋白质相互作用网络——支持模块检测、邻近性检验、富集分析与可复现导出。

📈

数据浏览与分析

提供生物标志物浏览器、网络探索器和交互式可视化工具，包括UMAP图和网络图。

🔍

高级搜索功能

具有多重过滤器和研究数据导出选项的强大搜索功能，支持保存搜索条件。

🌐

开放获取平台

为结直肠癌研究社区提供所有数据和工具的免费开放访问，支持API访问和多种导出格式。
