Build, expand and statistically analyze protein-protein interaction networks with STRING integration - module detection, proximity testing, enrichment analysis and reproducible exports.

Open Access Platform

Free and open access to all data and tools for the colorectal cancer research community, supporting API access and multiple export formats.
